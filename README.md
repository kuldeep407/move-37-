# Video Editing Backend API

A backend service for a video editing platform that supports:
- Video upload
- Trimming
- Subtitles overlay
- Rendering and download of final video

Built with **Node.js**, **Express.js**, **PostgreSQL (via Prisma)**, **FFmpeg**, and **Multer**.

## Tech Stack used in this project

- Node.js
- Express.js
- Prisma + PostgreSQL
- FFmpeg (via fluent-ffmpeg)
- Multer (file uploads)

## Getting Started

# Clone the repository
git clone https://github.com/kuldeep407/move-37-.git

# Navigate to the project directory
cd video-editing-backend

# Install project dependencies
npm install

# Run the server
npm start
